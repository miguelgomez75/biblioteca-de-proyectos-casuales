My GitHub Activity Pet

Esta mascota vive del código: duerme, despierta y se pone cada vez más contenta según los commits que hago cada día. A medianoche vuelve a dormirse y empieza de nuevo.

¿Quieres una para tu propio perfil?:

  1. Copia scripts/pet.py y .github/workflows/pet.yml a tu repo TU_USUARIO/TU_USUARIO.
  2. Sube tus propios sprites (.gif/.png/.jpg) a assets/sprites/, con los nombres de cada estado.
  3. Si quieres poner distintos sprites en ciertas fechas analiza skins.json y asegúrate de que los sprites estén en directorios con los nombres adecuados.
  4. En Settings → Actions → General, activa "Read and write permissions".
  5. Ejecuta el workflow una vez desde la pestaña Actions.
  6. Pega la tabla de tu README apuntando a dist/pet.gif y dist/pet-status-*.svg.

Los datos se leen en directo desde la API pública de GitHub (api.github.com) y raw.githubusercontent.com — no se envían a ningún otro servidor.
Se excluyen del análisis las carpetas de secretos/configuración privada. Los resultados se guardan en caché en este navegador durante 10 minutos.

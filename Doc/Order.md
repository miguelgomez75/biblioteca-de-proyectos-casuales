# order::hub — Agrupar y organizar

**order::hub** es una aplicación web *standalone* diseñada para agrupar, ordenar y clasificar elementos o personas dentro de categorías personalizadas[cite: 10]. Toda la interfaz funciona en tiempo real en el navegador de manera 100% cliente, almacenando tus datos localmente[cite: 10].

---

## 🚀 Características principales

- **Gestión de tableros múltiples:** Crea, renombra, alterna o elimina distintos tableros de trabajo de forma independiente[cite: 10].
- **Elementos con imagen:** Añade elementos especificando su nombre e incluye imágenes mediante URL o subiendo un archivo local (compresión y escalado automático a Canvas)[cite: 10].
- **Bandeja "Sin asignar":** Espacio temporal para almacenar los elementos que aún no han sido clasificados[cite: 10].
- **Grupos y cupos máximos:** Crea grupos personalizados estableciendo un límite máximo de elementos (capacidad/cupo)[cite: 10].
- **Interacción fluida (Drag & Drop + Móvil):** Organiza arrastrando tarjetas hacia los grupos o utiliza el desplegable integrado para mayor comodidad en dispositivos táctiles[cite: 10].
- **Persistencia local y Portabilidad:** Guarda automáticamente el estado en `localStorage` y permite exportar e importar tableros completos en formato JSON[cite: 10].

---

## 🛠️ Tecnologías utilizadas

- **HTML5:** Estructura semántica[cite: 10].
- **CSS3:** Variables CSS, grid dinámico, animaciones y diseño completamente *responsive*[cite: 10].
- **JavaScript (ES6+ Native):** Lógica sin dependencias externas, Canvas API para optimización de imágenes y Drag & Drop API[cite: 10].

---

## 📂 Uso del proyecto

Simplemente abre el archivo `Order.html` en cualquier navegador web moderno[cite: 10]. No requiere instalación ni servidores Node.js.
